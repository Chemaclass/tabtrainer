    Writing a song

    A song is plain text: a few header lines, then bars of notes separated by |.

    title: My groove
instrument: bass4      # bass4, bass5, bass6, guitar6, ukulele
tuning: D2 A2 D3 G3    # optional: any tuning, low to high
tempo: 90
key: C                 # e.g. C, Ab, F#m
time: 4/4

@Verse                 # section name
"C" :q 3.3 3.3 :8 5.2 5.2 :q 3.3 |
(3.3 5.2):h r:h |      # chord + rest
[3/4] :8t 3.3 5.3 7.3 :q ~7.3 r |
    3.4fret 3 on string 4 (string 1 = highest)
    :qset the duration for the next notes: w h q 8 16 32, add . for dotted, t for triplets
    3.4:8duration on a single note
    (3.4 5.3)notes struck together
    rrest
    ~5.3tied: keep the note ringing, don't pick again
    "Am7"chord name above the next note
    {let ring}text above the next note (dynamics, tips)
    [3/4]time signature from this bar on
    @Chorussection name (own line)
    # …comment
