# Each beat is a long note and a short one: "daa-da". That uneven feel is the shuffle. Index finger on fret 2, ring finger on fret 4. For A, move the same shape over one string. On B there is no open root: index on fret 2 of string 5, ring on fret 4 of string 4. Its sixth would need a four-fret reach, so B keeps the plain shape.
