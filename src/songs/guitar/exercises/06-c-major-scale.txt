title: C Major Scale
artist: TabTrainer
about: Play the C major scale in open position with one finger per fret, first with down strokes, then with strict down-up picking.
level: easy
instrument: guitar6
tempo: 72
key: C
time: 4/4

# One finger per fret: index on fret 1, middle on fret 2, ring on fret 3. Open strings fill the gaps.
# {d} means pick down, toward the floor; {u} means pick up. In eighths and sixteenths keep alternating d u d u.

== Learn
level: easy
@Up
# Quarter notes: pick every note down.
:q {d} 3.5 {d} 0.4 2.4 3.4 | 0.3 2.3 0.2 1.2 |
@Down
1.2 0.2 2.3 0.3 | 3.4 2.4 0.4 3.5 |

== Develop
level: medium
@Up to G
# Eighth notes: down on the beat, up on the "and" in between.
:8 {d} 3.5 {u} 0.4 2.4 3.4 0.3 2.3 0.2 1.2 | 3.2 0.1 1.1 3.1 1.1 0.1 3.2 1.2 |
@Back down
0.2 2.3 0.3 3.4 2.4 0.4 3.5 0.4 | :q 2.4 0.4 :h 3.5 |

== Challenge
level: hard
@Thirds
# Skip a note, then step back: C E, D F, E G on the way up, and C A, B G, A F on the way down.
:8 {d} 3.5 {u} 2.4 0.4 3.4 2.4 0.3 3.4 2.3 | 0.3 0.2 2.3 1.2 1.2 2.3 0.2 0.3 |
2.3 3.4 0.3 2.4 3.4 0.4 2.4 3.5 | 0.4 2.5 3.5 2.4 :h 3.5 |
@Groups of four
# Four notes up, then start again one note higher. From the top C, come back down the same way.
:8 {d} 3.5 {u} 0.4 2.4 3.4 0.4 2.4 3.4 0.3 | 2.4 3.4 0.3 2.3 3.4 0.3 2.3 0.2 |
1.2 0.2 2.3 0.3 0.2 2.3 0.3 3.4 | 2.3 0.3 3.4 2.4 :q 0.4 3.5 |
@Skips
# Up a fourth, down a step, and on up the scale. Coming down, reverse it: down a fourth, up a step, down to the low E string. The last bar walks up to C.
:8 {d} 3.5 {u} 3.4 2.4 2.3 0.3 1.2 0.2 0.1 | 3.2 3.1 1.1 1.2 3.2 2.3 0.2 3.4 |
0.3 0.4 2.4 2.5 3.5 3.6 0.5 0.6 | 1.6 3.6 0.5 2.5 :h 3.5 |
@Sixteenth run
# Up an octave and back in one bar, from C and then from G, and finish down from high G to C. Keep the pick going d u d u.
:16 {d} 3.5 {u} 0.4 2.4 3.4 0.3 2.3 0.2 1.2 0.2 2.3 0.3 3.4 2.4 0.4 :8 3.5 | :16 0.3 2.3 0.2 1.2 3.2 0.1 1.1 3.1 1.1 0.1 3.2 1.2 0.2 2.3 :8 0.3 |
:16 3.5 0.4 2.4 3.4 0.3 2.3 0.2 1.2 0.2 2.3 0.3 3.4 2.4 0.4 :8 3.5 | :16 3.1 1.1 0.1 3.2 1.2 0.2 2.3 0.3 :h 3.5 |
